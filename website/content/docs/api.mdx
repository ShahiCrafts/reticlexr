This reference is hand-written from the source. The library is plain
JavaScript with JSDoc; hand-written TypeScript declarations ship with
the package (the JSDoc is type-checked in the repo), but this page is
still maintained by hand rather than generated. Every signature below
was verified against `src/` (and `android/` for the native facade).
Where the JSDoc in the code disagrees with the implementation, this
page documents the **implementation** and says so.

## Package exports

```js
import ARCore, {
  useARCore,
  createARGestureController,
  ARView,
  createARView,
  takeScreenshot,
  enableCustomization,
  addTextures,
  switchModel,
  placeModel,
} from 'reticlexr';
```

| Export | Kind | Layer |
| --- | --- | --- |
| `ARCore` (default) | Native facade object | Capacitor bridge → Android ARCore (web → WebXR engine) |
| `ARView`, `createARView` | Class + factory | High-level facade over the WebXR engine |
| `takeScreenshot`, `enableCustomization`, `addTextures`, `switchModel`, `placeModel` | Functional helpers (view-first) | Same facade, function style |
| `useARCore` | React hook | WebXR engine mirrored into React state — supported entry: **`reticlexr/react`**; the root re-export is deprecated |
| `createARGestureController` | Factory | Standalone Pointer Events controller |

<Note>
One identifier everywhere: **`modelId`**. The WebXR engine historically
called the same id `anchorId`; since 1.1.0 every layer returns and
accepts `modelId` (its value is unchanged — it is the engine's anchor
id), and `anchorId` remains as a deprecated alias on inputs, results
and event payloads until the next major version. Using `anchorId` as
an input logs a one-time deprecation warning.
</Note>

## ARCore native facade

The default export. Every method delegates to the Capacitor plugin
registered as `ARCore` — on Android that's the native plugin, on web it
falls through to the WebXR engine (`ARCoreWeb`). Errors reject with an
`Error` carrying a stable `code` (see
[Error conventions](#error-conventions)); the message keeps the
`'Failed to …: '` prefix. `checkSupport` resolves a failure object
instead.

```js title="native-facade.js"
import ARCore from 'reticlexr';

const support = await ARCore.checkSupport();
if (support.supported) {
  await ARCore.startSession({ planeDetection: true, lightEstimation: true });
  const { modelId } = await ARCore.placeModel({ modelPath: '/models/sofa.glb' });
  await ARCore.setTransform({ modelId, rotation: { x: 0, y: 45, z: 0 }, scale: 1.2 });
  await ARCore.setMaterial({ modelId, color: '#68705b' });
  await ARCore.removeModel({ modelId });
  await ARCore.stopSession();
}
```

| Method | Signature | Returns |
| --- | --- | --- |
| `startSession` | `(options?: { planeDetection = true, lightEstimation = true })` | `Promise<{ success: boolean }>` |
| `stopSession` | `()` | `Promise<void>` |
| `hitTest` | `(options: { x: number, y: number })` — normalised [0, 1] | `Promise<Object>` — `{ hit, position?, rotation?, planeType?, code?, error? }` |
| `placeModel` | `(options: { modelPath: string, hitId?: string })` — `modelUrl` accepted as an alias for `modelPath`; the facade forwards both so one shape works on both runtimes | `Promise<{ modelId: string, anchorId: string }>` |
| `setTransform` | `(options: { modelId, rotation?: {x,y,z} degrees, scale?: number })` | `Promise<void>` |
| `setMaterial` | `(options: { modelId, color: string })` — hex color | `Promise<void>` |
| `moveModel` | `(options: { modelId, x: number, y: number })` | `Promise<Object>` |
| `removeModel` | `(options: { modelId })` | `Promise<void>` |
| `getPlacedModels` | `()` | `Promise<Array<{ modelId, modelUrl, position, rotation, scale }>>` — web returns the engine's list; the Android plugin method lands with the native remediation phase (rejects there until then) |
| `clearModels` | `()` | `Promise<void>` — same Android caveat |
| `checkSupport` | `()` | `Promise<{ supported: boolean, reason: string, code?: string }>` |
| `on` | `(eventType: string, callback: (data) => void)` | unsubscribe function `() => void` |
| `addListener` | `(eventType, callback)` | Capacitor listener handle (internal) |

<Warning>
Native-runtime reality check (verified in the audit): on Android today
the session, hit test and events are real, but `placeModel` registers
model metadata without rendering anything, `moveModel` resolves success
without moving the model, the `hitId` option is ignored (every placement
uses the anchor id `"anchor_center"`), and `checkSupport` resolves
`supported: true` unconditionally. WebXR is the runtime that renders
models. See [WebXR vs native ARCore](/docs/concepts/webxr-vs-native).
</Warning>

### Facade events

`ARCore.on(eventType, callback)` subscribes to the local event bus, fed
by the native event bridge — installed lazily on the first subscription
(and idempotently), not at import time:

```js
const off = ARCore.on('modelPlaced', (data) => console.log(data));
off(); // unsubscribe
```

Wired event types: `sessionStarted`, `trackingChanged`,
`surfaceDetected`, `surfaceLost`, `surfaceUpdated`, `sessionStopped`,
`modelPlaced`, `modelRemoved`, `modelTransformed`,
`modelMaterialChanged`, `modelMoved`, `error`.

## ARView and createARView

The framework-agnostic facade over one WebXR engine instance. This is
the API the guides and the example use.

```js
import { createARView } from 'reticlexr';

const ar = createARView({ overlay: document.querySelector('#ar-overlay') });
```

Constructor options: `{ engine?, overlay? }` — `engine` is an `ARCoreWeb`
instance (default: a new one), `overlay` the DOM element for the
immersive session's overlay.

### Session

| Member | Signature / behaviour |
| --- | --- |
| `checkSupport()` | → engine `checkSupport()` → `{ supported, reason }` |
| `create(options?)` | Starts the session. Options: `{ overlay?, showReticle = true, showPlanes (forced false), showPlaneDots = true, dotSpacing = 0.14, dotSize = 0.014, showShadow = true, planeDetection = true, lightEstimation = true }`. Resolves `{ success, hasOverlay, planeDetection }` |
| `destroy()` | Destroys gestures, then `await engine.stopSession()` |
| `onFrame(cb)` / `onPlanes(cb)` | Subscribe to engine frame / plane listeners; both return an unsubscribe function |
| `getSurface()` | Current surface state `{ hasSurface, position, rotation, planeType, confidence }` |
| `getPlanes()` | `[{ orientation, polygon: [{x, y, z}] }]` |
| `setReticleVisible(v)` / `setSurfaceDotsVisible(v)` | Visibility toggles |

```js title="session.js"
await ar.create({ showReticle: true, showPlaneDots: true, dotSpacing: 0.14 });
const off = ar.onPlanes((e) => console.log(e.total, 'planes'));
console.log(ar.getSurface().planeType); // e.g. 'horizontal'
await ar.destroy();
off();
```

### Models

| Member | Signature / behaviour |
| --- | --- |
| `preloadModels(urls)` | Loads each URL into the engine cache (`Promise.all`) |
| `placeModel(modelUrl, options?)` | Options: `{ position?, rotation?, x = 0.5, y = 0.5, scale? }`. Hit-tests the centre (or `x, y`) unless `position` is given. Resolves `{ success: true, modelId, anchorId, … }` or `{ success: false, code: 'NO_SURFACE', reason: 'NO_SURFACE' }` (`reason` is a deprecated alias of `code`). Sets `activeModelId` / `activeModelUrl` and tracks the placement |
| `switchModel(modelUrl, options?)` | Options: `{ preserveMaterial = true }`. Keeps placement/transform; falls back to `placeModel` when nothing is placed |
| `removeModel()` | Removes the active model; no-op if none |
| `getPlacedModels()` | Lists every model placed through this view, with current transforms |
| `clearModels()` | Removes every model placed through this view (disposal follows the ownership rule) |
| `setScale(scale)` | Clamped to **[0.1, 5]**, applied uniformly |
| `rotateBy(radians)` | Accumulates `transform.rotationY`, applies a Y rotation |
| `setColor(color)` | Sets the active model's color (hex string) |
| `addTextures({ name: url })` | Registers named texture URLs; returns `this` |
| `applyTexture(nameOrUrl, options?)` | Options: `{ materialName? }`. Throws if no model is placed |
| `takeScreenshot(options?)` | Delegates to the engine — see [Screenshots](/docs/guides/screenshots) |
| Public fields | `activeModelId`, `activeModelUrl`, `transform` (`{ scale: 1, rotationY: 0 }`), `textures` (a `Map`) |

```js title="models.js"
await ar.preloadModels(['/models/sofa.glb', '/models/chair.glb']);
const placed = await ar.placeModel('/models/sofa.glb');
if (placed.success) {
  ar.setScale(1.25);
  ar.rotateBy(Math.PI / 6);
  await ar.switchModel('/models/chair.glb'); // same anchor, scale, rotation
  await ar.setColor('#222b3c');
  await ar.removeModel();
}
```

### Customization and gestures

`enableCustomization(options?)` wires the gesture controller to the
overlay. It **throws without an overlay**. Options:
`{ modelUrl: () => string, onTap?, onScale?, onRotate? }` — note
`modelUrl` is invoked as a function on every tap. Returns a cleanup
function. Full details in [Gestures](/docs/guides/gestures).

### Functional helpers

The same operations, view-first, for function-style codebases:

```js
import { placeModel, switchModel, addTextures, enableCustomization, takeScreenshot } from 'reticlexr';

await placeModel(ar, '/models/sofa.glb');
await switchModel(ar, '/models/chair.glb', { preserveMaterial: false });
addTextures(ar, { oak: '/textures/oak.jpg' });
const cleanup = enableCustomization(ar, { modelUrl: () => '/models/sofa.glb' });
const shot = await takeScreenshot(ar, { format: 'jpeg', quality: 0.85 });
```

## ARCoreWeb engine

The WebXR engine class behind everything above (`new ARCoreWeb()`).
Advanced consumers can use it directly — the hook does. Methods used by
the layers above:

### Configuration

`setConfig(partial)` / `getConfig()`. Defaults:

| Key | Default | Key | Default |
| --- | --- | --- | --- |
| `showReticle` | `true` | `reticleColor` | `0x00ff88` |
| `showPlanes` | `false` | `reticleColorVertical` | `0xff6b6b` |
| `showPlaneDots` | `true` | `planeColorHorizontal` | `0x00ff88` |
| `showShadow` | `true` | `planeColorVertical` | `0xff6b6b` |
| `showBaseRing` | `false` | `shadowOpacity` | `0.4` |
| `dotSize` | `0.02` | `shadowSize` | `1.2` |
| `dotSpacing` | `0.1` | | |

<Note>
The facade's `create()` overrides some of these per view (dots at
spacing `0.14`, size `0.014`). Engine defaults apply when you drive the
engine directly.
</Note>

### Session and accessors

`checkSupport()`, `startSession({ planeDetection = true, lightEstimation = true, domOverlay = null })`,
`stopSession()`, `getSession()`, `getRenderer()`, `getScene()`,
`getCamera()`, `getAnchors()`.

<Todo>
The engine class has its own subpath export: `reticlexr/web`
(`import { ARCoreWeb } from 'reticlexr/web'`). You can also reach a
live engine through `ARView`'s `ar.engine` field, or use the hook's
accessors (`getRenderer` / `getScene` / `getCamera`).
</Todo>

### Models

| Method | Signature / behaviour |
| --- | --- |
| `loadModel(url)` | Loads (or returns the cache entry) and resolves a fresh `gltf.scene.clone()` |
| `placeModel({ modelUrl \| modelPath, position?, rotation = [0,0,0,1], scale = [1,1,1] })` | Resolves `{ modelId, anchorId }` (`modelPath` is a deprecated alias for `modelUrl`) |
| `removeModel({ modelId })` | Removes the model from the scene (`{ anchorId }` accepted as a deprecated alias) |
| `transformModel({ modelId, position?, rotation?, scale? })` | Applies a transform |
| `switchModel({ modelId, modelUrl, preserveMaterial = true })` | Swaps the model at an existing placement |
| `setModelColor({ modelId, color })` | Recolors |
| `setModelMaterial({ modelId, metalness?, roughness?, opacity? })` | PBR property update |
| `setModelTexture({ modelId, textureUrl, materialName? })` | Applies a texture |
| `getPlacedModels()` | Lists placed models: `{ modelId, modelUrl, position, rotation, scale }` entries |
| `clearModels()` | Removes every placed model; per-instance disposal, cache survives |
| `setTransform(options)` / `setMaterial(options)` / `moveModel(options)` | Facade-compatibility shims accepting `modelId` (or the deprecated `anchorId`) |

```js title="engine-models.js"
const { modelId } = await engine.placeModel({
  modelUrl: '/models/sofa.glb',
  position: [0, 0, -1.5],
  rotation: [0, 0, 0, 1], // quaternion
  scale: [1, 1, 1],
});
await engine.setModelMaterial({ modelId, roughness: 0.8 });
await engine.removeModel({ modelId });
```

### Queries, events and visualisation

| Method | Behaviour |
| --- | --- |
| `hitTest({ x, y })` | Resolves `{ hit, position?, rotation?, planeType?, code?, error? }`. The centre point uses the cached viewer-ray hit; any other point runs a real ray hit test through the camera pose |
| `getSurfaceState()` / `getSurfaceDetectionState()` | Current surface state |
| `getDetectedPlanes()` | Detected plane list |
| `addFrameListener(cb)` / `addPlaneListener(cb)` | Subscribe; return unsubscribe |
| `setReticleVisible(v)` | Toggle the reticle |
| `setPlaneVisualization(v)` / `isPlaneVisualizationEnabled()` | Plane mesh visualisation |
| `setShadowVisible(modelId, v)` | Per-model shadow toggle |
| `setShadowConfig({ enabled?, opacity?, size? })` / `getShadowConfig()` | Shadow tuning |
| `clearModelCache()` | Dispose every cached model's GPU resources and empty the cache (live placements re-upload on the next frame) |
| `dispose()` | Full engine teardown: session, scene resources, model cache, renderer and GL context. The engine can be started again afterwards |

Frame listeners receive engine events: `surfaceDetected` (on change,
then at most 10 Hz while the centre ray has a hit), `surfaceLost`, `modelPlaced`, `modelRemoved`,
`modelTransformed`, `modelColorChanged`, `modelSwitched`,
`sessionEnded`. Plane listeners receive `planeAdded` and `planesUpdated`
with payload `{ type, total, horizontal, vertical }` — counts as
**numbers**.

### Screenshots

`takeScreenshot({ format = 'png', quality = 0.92, width?, height?, includeReticle? })`
resolves `{ success, dataUrl, width, height, timestamp, includesCamera }`
or `{ success: false, code?, error }` with `code` one of
`'CAMERA_CAPTURE_UNAVAILABLE'`, `'CAPTURE_BUSY'`. Requires the session
to have been started with `enableScreenshots: true` (camera access is
opt-in; `lightEstimation` does not enable it) — without it the result
is `CAMERA_CAPTURE_UNAVAILABLE`. See
[Screenshots](/docs/guides/screenshots).

## useARCore

React hook over the WebXR engine — import it from **`reticlexr/react`**.
It checks support on mount and mirrors engine events into state.

By default all consumers share one engine (constructed lazily on first
use). Pass an engine for an instance-scoped hook:
`useARCore({ engine })` — the engine is fixed at mount, so multiple
independent AR views can coexist.

**State:** `isSupported: boolean | null`, `isSessionActive: boolean`,
`placedModels: Array<{ modelId, anchorId, modelUrl, position, rotation, scale }>`
(`anchorId` is the deprecated alias of `modelId`, same string),
`error: string | null`,
`detectedPlanes: { horizontal, vertical, total }`,
`surfaceState: { hasSurface, position, rotation, planeType, confidence }`.

**Methods** (all memoised): `startSession(options)` →
`Promise<boolean>` (options pass straight to the engine, e.g.
`{ domOverlay }`), `stopSession()`, `hitTest(x, y)`,
`placeModel(modelUrl, position, rotation, scale)`,
`removeModel(modelId)`, `getPlacedModels()`, `clearModels()`,
`transformModel(modelId, transforms)`,
`setModelColor(modelId, color)`, `setModelMaterial(modelId, properties)`,
`setConfig` / `getConfig`, `setShadowConfig` / `getShadowConfig`,
`setShadowVisible(modelId, v)`, `getDetectedPlanes()`,
`setReticleVisible(v)`, `setPlaneVisualization(v)`, `clearError()`,
`getRenderer` / `getScene` / `getCamera`, `takeScreenshot(options)`.

```jsx title="hook.jsx"
import { useARCore } from 'reticlexr/react';

const ar = useARCore();

await ar.startSession({ domOverlay: overlayElement });
await ar.placeModel('/models/sofa.glb', [0, 0, -1.5], [0, 0, 0, 1], [1, 1, 1]);
// Placed models are mirrored into state:
const first = ar.placedModels[0];
if (first) ar.setModelColor(first.modelId, '#a55f3b');
```

<Warning>
Hook contract traps, verified against the engine:

- `placeModel` transform arguments are **arrays** (position `[x,y,z]`,
  rotation quaternion `[x,y,z,w]`, scale `[sx,sy,sz]`). The hook's JSDoc
  describes `{x, y, z}` objects — objects produce `NaN` transforms.
- `detectedPlanes` state currently never updates (it reads array fields;
  the engine emits numeric counts). Use a plane listener instead.
- All hook consumers share one engine; one consumer unmounting stops the
  session for everyone. Mount it once.
</Warning>

## Gesture controller

```js
import { createARGestureController } from 'reticlexr';

const gestures = createARGestureController({
  element,                  // required — throws if missing
  onTap, onDrag, onPinch, onRotate,
  tapMaxDuration = 260,     // ms
  tapMaxDistance = 12,      // px
  preventDefault = true,
  ignoreSelector = '[data-ui]',
});
gestures.destroy();
```

Payloads: `onTap({ x, y })`, `onDrag({ dx, dy, x, y })`,
`onPinch({ factor, center })` with an **incremental** factor,
`onRotate({ delta, center })` with an incremental delta in radians
wrapped to ±π. Full guide: [Gestures](/docs/guides/gestures).

## Error conventions

One convention since 1.1.0: **every public failure carries a stable,
machine-readable `code`** (SCREAMING_SNAKE, stable across versions).

| Layer | Convention |
| --- | --- |
| Async methods (engine, facade, `ARView`, hook internals) | Reject with an `ARError` — an `Error` with a `code` property (`ARError` and `codedError` are exported from the package root and `reticlexr/web`) |
| `hitTest` (engine + hook) | Resolves `{ hit: false, code, error }` — never rejects for a missed/failed test |
| `takeScreenshot` | Resolves `{ success: false, code, error }` |
| `ARView.placeModel` | Resolves `{ success: false, code: 'NO_SURFACE', reason: 'NO_SURFACE' }` (`reason` is a deprecated alias of `code`) |
| `ARCore.checkSupport` | Resolves `{ supported: false, reason, code? }` |
| `useARCore` | Sets `error` state (the message); failure results also carry `code` |

Codes in use include `MODEL_NOT_FOUND`, `MODEL_URL_REQUIRED`,
`MODEL_LOAD_FAILED`, `NO_SURFACE`, `SESSION_NOT_ACTIVE`,
`SESSION_START_FAILED`, `SESSION_ENDED`, `HIT_TEST_TIMEOUT`,
`CAMERA_CAPTURE_UNAVAILABLE`, `CAPTURE_BUSY` and `INSECURE_CONTEXT`.
Error messages are unchanged from v1.0.0 — only the `code` was added.
