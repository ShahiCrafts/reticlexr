This reference is hand-written from the source and the shipped
type declarations (`src/*.d.ts`, kept honest against the
implementation by `tsc --checkJs`). Where the JSDoc in the code
disagrees with the implementation, this page documents the
**implementation** and says so.

## Package exports

```js
import ARCore, {
  ARError,
  ARView,
  createARView,
  createARGestureController,
  takeScreenshot,
  enableCustomization,
  addTextures,
  switchModel,
  placeModel,
} from 'reticlexr';
import { useARCore } from 'reticlexr/react';
import { ARCoreWeb } from 'reticlexr/web';
```

| Export | Kind | Layer |
| --- | --- | --- |
| `ARCore` (default) | Native facade object | Capacitor bridge → Android plugin (web → WebXR engine) |
| `ARView`, `createARView` | Class + factory | High-level facade over the WebXR engine |
| `takeScreenshot`, `enableCustomization`, `addTextures`, `switchModel`, `placeModel` | Functional helpers (view-first) | Same facade, function style |
| `useARCore` | React hook — import from `reticlexr/react` | WebXR engine mirrored into React state |
| `ARCoreWeb` | Engine class — import from `reticlexr/web` | The WebXR runtime itself |
| `createARGestureController` | Factory | Standalone Pointer Events controller |
| `ARError`, `codedError` | Error class + factory | The package's one error convention |

Subpaths: `.`, `./react`, `./web`, `./ar-view`, `./gestures`,
`./package.json`. Deep imports outside the exports map do not
resolve.

<Note>
One identifier everywhere: a placed model is a **`modelId`** on
every layer and runtime (API-01). `anchorId` survives as a
**deprecated alias** — the same string — on inputs, results and
event payloads, and is removed in the next major version.
</Note>

## ARCore native facade

The default export. Every method delegates to the Capacitor plugin
registered as `ARCore` — on Android that's the native plugin, on
web it falls through to the WebXR engine (`ARCoreWeb`). Failures
reject with an `ARError` carrying a stable `code` (a runtime code
when one exists, otherwise a per-method `*_FAILED` fallback);
`checkSupport` resolves a result object instead.

```js title="native-facade.js"
import ARCore from 'reticlexr';

const support = await ARCore.checkSupport();
if (support.supported) {
  await ARCore.startSession({ planeDetection: true, lightEstimation: true });
  const hit = await ARCore.hitTest({ x: 0.5, y: 0.5 });
  await ARCore.stopSession();
}
```

| Method | Signature | Returns |
| --- | --- | --- |
| `startSession` | `(options?: { planeDetection?, lightEstimation? })` | `Promise<{ success: boolean }>` |
| `stopSession` | `()` | `Promise<void>` |
| `hitTest` | `(options: { x: number, y: number })` — normalised [0, 1] | `Promise<{ hit, position?, rotation?, planeType?, error? }>` |
| `placeModel` | `(options: { modelPath: string, hitId?: string } \| { modelUrl: string, hitId?: string })` | `Promise<{ modelId: string, anchorId: string }>` |
| `setTransform` | `(options: { modelId, rotation?: {x,y,z} degrees, scale?: number })` | `Promise<void>` |
| `setMaterial` | `(options: { modelId, color: string })` — hex color | `Promise<void>` |
| `moveModel` | `(options: { modelId, x: number, y: number })` | `Promise<Object>` |
| `removeModel` | `(options: { modelId })` | `Promise<void>` |
| `getPlacedModels` | `()` | `Promise<Array<{ modelId, modelUrl, position, rotation, scale }>>` |
| `clearModels` | `()` | `Promise<void>` |
| `checkSupport` | `()` | `Promise<{ supported: boolean, reason: string, code?: string }>` |
| `on` | `(eventType: string, callback: (data) => void)` | unsubscribe function `() => void` |
| `addListener` | `(eventType, callback)` | Capacitor listener handle (internal) |

<Warning>
Native-runtime scope (Option B): on Android the session, hit test
and events are real — `checkSupport` returns the actual
`ArCoreApk.checkAvailability()` result and a successful hit test
creates a real ARCore anchor. But the native plugin does **not**
render models: `placeModel`, `moveModel`, `setTransform`,
`setMaterial`, `removeModel`, `getPlacedModels` and `clearModels`
reject with code `NOT_IMPLEMENTED`. WebXR is the runtime that
renders models. See
[WebXR vs native ARCore](/docs/concepts/webxr-vs-native).
</Warning>

### Facade events

`ARCore.on(eventType, callback)` subscribes to the local event bus,
fed by the native event bridge — which installs **lazily on the
first subscription** (importing the package has no listener side
effects):

```js
const off = ARCore.on('modelPlaced', (data) => console.log(data));
off(); // unsubscribe
```

Wired event types: `sessionStarted`, `trackingChanged`,
`surfaceDetected`, `surfaceLost`, `surfaceUpdated`, `sessionStopped`,
`modelPlaced`, `modelRemoved`, `modelTransformed`,
`modelMaterialChanged`, `modelMoved`, `error`. Events are per
runtime — the WebXR engine emits its own set through its listeners
(below), never through `ARCore.on`.

## ARView and createARView

The framework-agnostic facade over one WebXR engine instance. This
is the API the guides and the example use.

```js
import { createARView } from 'reticlexr';

const ar = createARView({ overlay: document.querySelector('#ar-overlay') });
```

Constructor options: `{ engine?, overlay? }` — `engine` is an
`ARCoreWeb` instance (default: a new one), `overlay` the DOM
element for the immersive session's overlay.

### Session

| Member | Signature / behaviour |
| --- | --- |
| `checkSupport()` | → engine `checkSupport()` → `{ supported, reason, code? }` |
| `create(options?)` | Starts the session. Options: `{ overlay?, showReticle = true, showPlaneDots = true, dotSpacing = 0.14, dotSize = 0.014, showShadow = true, planeDetection = true, lightEstimation = true, enableScreenshots = false }`. Resolves `{ success, hasOverlay, planeDetection }` |
| `destroy()` | Destroys gestures, then fully disposes the engine (`engine.dispose()`) |
| `onFrame(cb)` / `onPlanes(cb)` | Subscribe to engine frame / plane listeners; both return an unsubscribe function |
| `getSurface()` | Current surface state `{ hasSurface, position, rotation, planeType, confidence }` |
| `getPlanes()` | `[{ orientation, polygon: [{x, y, z}] }]` |
| `setReticleVisible(v)` / `setSurfaceDotsVisible(v)` | Visibility toggles |

```js title="session.js"
await ar.create({ showReticle: true, showPlaneDots: true, dotSpacing: 0.14 });
const off = ar.onPlanes((e) => console.log(e.total, 'planes'));
console.log(ar.getSurface().planeType); // e.g. 'horizontal'
await ar.destroy();
off();
```

### Models

| Member | Signature / behaviour |
| --- | --- |
| `preloadModels(urls)` | Loads each URL into the engine cache (`Promise.all`) |
| `placeModel(modelUrl, options?)` | Options: `{ position?, rotation?, x = 0.5, y = 0.5, scale? }`. Hit-tests (centre, or `x, y`) unless `position` is given. Resolves `{ success: true, modelId, … }` or `{ success: false, code: 'NO_SURFACE', reason }` (`reason` is a deprecated alias of `code`). Sets `activeModelId` / `activeModelUrl` |
| `switchModel(modelUrl, options?)` | Options: `{ preserveMaterial = true }`. Keeps placement/transform; falls back to `placeModel` when nothing is placed |
| `removeModel()` | Removes the active model; no-op if none |
| `getPlacedModels()` | Models placed through this view |
| `clearModels()` | Removes every model placed through this view |
| `setScale(scale)` | Clamped to **[0.1, 5]**, applied uniformly |
| `rotateBy(radians)` | Accumulates `transform.rotationY`, applies a Y rotation |
| `setColor(color)` | Sets the active model's color (hex string) |
| `addTextures({ name: url })` | Registers named texture URLs; returns `this` |
| `applyTexture(nameOrUrl, options?)` | Options: `{ materialName? }`. Throws if no model is placed |
| `takeScreenshot(options?)` | Delegates to the engine — see [Screenshots](/docs/guides/screenshots) |
| Public fields | `activeModelId`, `activeModelUrl`, `placedModelUrls` (Map), `transform` (`{ scale, rotationY }`), `textures` (a `Map`) |

```js title="models.js"
await ar.preloadModels(['/models/sofa.glb', '/models/chair.glb']);
const placed = await ar.placeModel('/models/sofa.glb');
if (placed.success) {
  ar.setScale(1.25);
  ar.rotateBy(Math.PI / 6);
  await ar.switchModel('/models/chair.glb'); // same anchor, scale, rotation
  await ar.setColor('#222b3c');
  await ar.removeModel();
}
```

### Customization and gestures

`enableCustomization(options?)` wires the gesture controller to
the overlay. It **throws without an overlay**. Options:
`{ modelUrl: string | (() => string), onTap?, onScale?,
onRotate?, onError? }` — `modelUrl` may be a URL string or a
function invoked on every tap; placement errors are delivered to
`onError`. Returns a cleanup function. Full details in
[Gestures](/docs/guides/gestures).

### Functional helpers

The same operations, view-first, for function-style codebases:

```js
import { placeModel, switchModel, addTextures, enableCustomization, takeScreenshot } from 'reticlexr';

await placeModel(ar, '/models/sofa.glb');
await switchModel(ar, '/models/chair.glb', { preserveMaterial: false });
addTextures(ar, { oak: '/textures/oak.jpg' });
const cleanup = enableCustomization(ar, { modelUrl: () => '/models/sofa.glb' });
const shot = await takeScreenshot(ar, { format: 'jpeg', quality: 0.85 });
```

## ARCoreWeb engine

The WebXR engine class behind everything above
(`import { ARCoreWeb } from 'reticlexr/web'`). Advanced consumers
can use it directly — the hook does.

### Configuration

`setConfig(partial)` / `getConfig()`. Defaults:

| Key | Default | Key | Default |
| --- | --- | --- | --- |
| `showReticle` | `true` | `reticleColor` | `0x00ff88` |
| `showPlanes` | `false` | `reticleColorVertical` | `0xff6b6b` |
| `showPlaneDots` | `true` | `planeColorHorizontal` | `0x00ff88` |
| `showShadow` | `true` | `planeColorVertical` | `0xff6b6b` |
| `showBaseRing` | `false` | `shadowOpacity` | `0.4` |
| `dotSize` | `0.02` | `shadowSize` | `1.2` |
| `dotSpacing` | `0.1` | `debug` | `false` |
| `modelCacheLimit` | `20` | | |

<Note>
The facade's `create()` overrides some of these per view (dots at
spacing `0.14`, size `0.014`). Engine defaults apply when you drive
the engine directly. `debug` gates the engine's diagnostic
logging; `modelCacheLimit` caps the GLTF cache (LRU; entries with
live placements are never evicted).
</Note>

### Session and accessors

`checkSupport()`, `startSession({ planeDetection = true,
lightEstimation = true, enableScreenshots = false,
domOverlay = null })`, `stopSession()`, `dispose()` (full
teardown; the instance can start again), `clearModelCache()`,
`getSession()`, `getRenderer()`, `getScene()`, `getCamera()`,
`getAnchors()`.

### Models

| Method | Signature / behaviour |
| --- | --- |
| `loadModel(url)` | Loads (or returns the cache entry) and resolves a fresh `gltf.scene.clone()` |
| `placeModel({ modelUrl, position?, rotation?, scale? })` | Resolves `{ modelId, anchorId }` (`anchorId` = deprecated alias). Inputs are normalised: position `[x,y,z]` or `{x,y,z}`; rotation quaternion or Euler radians; scale number/array/object, clamped to [0.1, 5] per axis |
| `removeModel({ modelId })` | Removes the model; disposal follows the ownership rule |
| `getPlacedModels()` | `[{ modelId, modelUrl, position, rotation, scale }]` |
| `clearModels()` | Removes every placed model |
| `transformModel({ modelId, position?, rotation?, scale? })` | Applies a model transform |
| `switchModel({ modelId, modelUrl, preserveMaterial = true })` | Swaps the model on an existing placement; material carry-over matches by name, then order |
| `setModelColor({ modelId, color })` | Recolors |
| `setModelMaterial({ modelId, metalness?, roughness?, opacity? })` | PBR property update |
| `setModelTexture({ modelId, textureUrl, materialName? })` | Applies a texture |
| `setTransform(options)` / `setMaterial(options)` / `moveModel(options)` | Facade-compatibility shims accepting `modelId` (or its `anchorId` alias); a plain `{x,y,z}` rotation in `setTransform` is Euler **degrees** |

```js title="engine-models.js"
const { modelId } = await engine.placeModel({
  modelUrl: '/models/sofa.glb',
  position: [0, 0, -1.5],
  rotation: [0, 0, 0, 1], // quaternion
  scale: [1, 1, 1],
});
await engine.setModelMaterial({ modelId, roughness: 0.8 });
await engine.removeModel({ modelId });
```

### Queries, events and visualisation

| Method | Behaviour |
| --- | --- |
| `hitTest({ x, y })` | Resolves `{ hit, position?, rotation?, planeType?, code? }`. Centre coordinates use the reticle path; non-centre coordinates perform a ray-based hit test |
| `hitTestAtPoint(x, y)` | The ray-based hit test directly |
| `getSurfaceState()` / `getSurfaceDetectionState()` | Current surface state |
| `getDetectedPlanes()` | Detected plane list |
| `addFrameListener(cb)` / `addPlaneListener(cb)` | Subscribe; return unsubscribe |
| `setReticleVisible(v)` | Toggle the reticle |
| `setPlaneVisualization(v)` / `isPlaneVisualizationEnabled()` | Plane mesh visualisation |
| `setShadowVisible(modelId, v)` | Per-model shadow toggle |
| `setShadowConfig({ enabled?, opacity?, size? })` / `getShadowConfig()` | Shadow tuning |

Frame listeners receive engine events: `surfaceDetected`,
`surfaceLost`, `modelPlaced`, `modelRemoved`, `modelTransformed`,
`modelColorChanged`, `modelSwitched`, `sessionEnded` — payloads
carry `modelId` (with `anchorId` as its deprecated alias). Plane
listeners receive `planeAdded` and `planesUpdated` with payload
`{ type, total, horizontal, vertical }` — counts as **numbers**.

### Screenshots

`takeScreenshot({ format = 'png', quality = 0.92, width?,
height?, includeReticle? })` resolves `{ success, dataUrl, width,
height, timestamp, includesCamera }` or `{ success: false, code?,
error }`. Including the camera feed needs the session started
with `enableScreenshots: true` — see
[Screenshots](/docs/guides/screenshots).

## useARCore

React hook over the WebXR engine, imported from
**`reticlexr/react`**. By default all consumers share one
lazily-constructed engine; pass `{ engine }` (a dedicated
`ARCoreWeb` from `reticlexr/web`) for an isolated, per-instance
hook. It checks support on mount and mirrors engine events into
state.

**State:** `isSupported: boolean | null`, `isSessionActive:
boolean`, `placedModels: Array<{ modelId, modelUrl, position,
rotation, scale }>`, `error: string | null`, `detectedPlanes:
{ horizontal, vertical, total }`, `surfaceState:
{ hasSurface, position, rotation, planeType, confidence }`.

**Methods** (all memoised): `startSession(options)` →
`Promise<boolean>` (options pass straight to the engine, e.g.
`{ domOverlay }`), `stopSession()`, `hitTest(x, y)` (normalised
[0, 1], origin top-left — not pixels),
`placeModel(modelUrl, position, rotation, scale)`,
`removeModel(modelId)`, `getPlacedModels()`, `clearModels()`,
`transformModel(modelId, transforms)`,
`setModelColor(modelId, color)`,
`setModelMaterial(modelId, properties)`, `setConfig` /
`getConfig`, `setShadowConfig` / `getShadowConfig`,
`setShadowVisible(modelId, v)`, `getDetectedPlanes()`,
`setReticleVisible(v)`, `setPlaneVisualization(v)`,
`clearError()`, `getRenderer` / `getScene` / `getCamera`,
`takeScreenshot(options)`.

```jsx title="hook.jsx"
import { useARCore } from 'reticlexr/react';

const ar = useARCore();

await ar.startSession({ domOverlay: overlayElement });
await ar.placeModel('/models/sofa.glb', [0, 0, -1.5], [0, 0, 0, 1], [1, 1, 1]);
// Placed models (with their modelIds) are mirrored into state:
const first = ar.placedModels[0];
if (first) ar.setModelColor(first.modelId, '#a55f3b');
```

<Note>
Transform arguments are **normalised**: positions accept
`[x, y, z]` or `{x, y, z}`, rotations a quaternion array/object or
Euler radians, scales a number, array or object. (In 1.0.0,
`{x, y, z}` objects produced `NaN` transforms — that was BUG-01,
fixed in 1.1.0.) With the shared default engine, one consumer
stopping the session stops it for all consumers — mount the hook
once, or pass a dedicated engine per view.
</Note>

## Gesture controller

```js
import { createARGestureController } from 'reticlexr';

const gestures = createARGestureController({
  element,                  // required — throws if missing
  onTap, onDrag, onPinch, onRotate,
  tapMaxDuration = 260,     // ms
  tapMaxDistance = 12,      // px
  preventDefault = true,
  ignoreSelector = '[data-ui]',
});
gestures.destroy();
```

Payloads: `onTap({ x, y })`, `onDrag({ dx, dy, x, y })`,
`onPinch({ factor, center })` with an **incremental** factor,
`onRotate({ delta, center })` with an incremental delta in
radians. Full guide: [Gestures](/docs/guides/gestures).

## Error conventions

One convention across the package (API-05): async methods reject
with an **`ARError`** — an `Error` with a stable, machine-readable
`code`. Result-object APIs resolve with the same `code` on their
failure results. Messages may change; codes are the contract.

| Layer | Convention |
| --- | --- |
| `ARCore` facade | Rejects with `ARError` (runtime code preserved; per-method `*_FAILED` fallback); `checkSupport` resolves `{ supported: false, reason, code }` |
| Engine `hitTest` | Resolves `{ hit: false, code, error }` |
| `ARView.placeModel` | Resolves `{ success: false, code, reason }` (`reason` = deprecated alias of `code`) |
| `useARCore` | Sets `error` state; failure results carry `code` |
| Screenshots | Resolve `{ success: false, code, error }` |

Engine codes include `SESSION_START_FAILED`,
`SESSION_NOT_ACTIVE`, `SESSION_ENDED`, `HIT_TEST_FAILED`,
`HIT_TEST_TIMEOUT`, `HIT_TEST_UNAVAILABLE`, `NO_VIEWER_POSE`,
`MODEL_NOT_FOUND`, `MODEL_URL_REQUIRED`, `MODEL_LOAD_FAILED`,
`NO_SURFACE`, `NO_ACTIVE_MODEL`, `OVERLAY_REQUIRED`,
`CAMERA_CAPTURE_UNAVAILABLE`, `CAPTURE_BUSY`, `INSECURE_CONTEXT`
— plus native codes surfaced unchanged (e.g. `NOT_IMPLEMENTED`,
`ACTIVITY_UNAVAILABLE`).

## Model and texture URLs

Model and texture URLs are loaded **as given** (three.js
`GLTFLoader` / `TextureLoader`); the package performs no
validation or allow-listing. Only load models and textures from
sources you control or trust — a GLB is parsed in your page's
origin, so an untrusted file is untrusted content. Cross-origin
URLs need CORS (`Access-Control-Allow-Origin`, over HTTPS) or
the load fails; same-origin or bundled assets avoid the issue.

## Deprecated aliases

All aliases keep working throughout 1.x and are removed in the
next major version.

| Deprecated | Replacement |
| --- | --- |
| `anchorId` (inputs, results, event payloads) | `modelId` — the same string |
| `modelPath` (engine `placeModel` option) | `modelUrl` |
| `reason` (ARView place result) | `code` — the same string |
| `useARCore` from the package root | `useARCore` from `reticlexr/react` |
