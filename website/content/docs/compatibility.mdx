## Native Android runtime (Capacitor)

| Item | Value | Notes |
| --- | --- | --- |
| Minimum Android SDK | 24 | `minSdk` default in `android/build.gradle` (overridable by the host project) |
| Compile / target SDK | 36 / 36 | Defaults, overridable |
| ARCore library | `com.google.ar:core` 1.40.0 | Device must be ARCore-capable with Google Play Services for AR |
| Filament | 1.52.0 | Camera-background rendering |
| Java | 21 | Source/target compatibility |

Tested Android versions and devices: **TODO** — none are recorded.

<Note>
The library's Android manifest declares the AR feature as
`required="true"`, which merges into your app: as shipped, a host app
becomes uninstallable on non-AR devices and AR-mandatory in store
listings. If your app must install on non-AR devices, this is a known
issue to weigh (see [Known issues](/docs/known-issues)).
</Note>

## Frameworks and tooling

| Item | Requirement | Notes |
| --- | --- | --- |
| React | `>=16.8.0` (peer) | Only the hook needs it conceptually — but v1.0.0's entry imports it unconditionally |
| `@capacitor/core` | `^8.5.2` (dependency) | Ships with the package |
| `three` | `^0.180.0` (dependency) | Ships with the package; declaring your own copy can duplicate it |
| Module format | ESM source, no `exports` map, no `type: module` | Bundlers cope; strict Node ESM resolution may not |
| TypeScript | No declarations shipped | JSDoc only |
