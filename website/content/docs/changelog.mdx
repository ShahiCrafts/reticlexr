All notable changes to this project are documented here. The project
follows [Semantic Versioning](https://semver.org/).

## 1.0.0 — 2026-09-25

### Added

- High-level `createARView()` abstraction.
- WebXR and Android ARCore integration layers.
- Surface detection, dotted plane feedback, and placement reticle.
- Tap-to-place, pinch-to-scale, and two-finger rotation gestures.
- GLB/GLTF loading, model preloading, and in-place model switching.
- Runtime material, color, and texture customization.
- AR screenshot API and React DOM overlay support.
- React/Vite example application with LAN HTTPS development tooling.

<Note title="Correction — read the parity claim carefully">
The original 1.0.0 entry lists "WebXR and Android ARCore integration
layers" side by side, which readers reasonably took as feature parity.
The v1.0.0 audit verified that the Android layer provides session
management, hit testing and surface events, but **does not render
models** — model rendering, styling and screenshots are WebXR-runtime
features. This note is the correction; the entry above is otherwise
reproduced as published. See
[WebXR vs native ARCore](/docs/concepts/webxr-vs-native) for the
verified split.
</Note>
