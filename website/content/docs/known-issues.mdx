This page summarises a full code audit of v1.0.0. The tone here is
deliberately plain: these are specific, located problems with known
fixes, not vibes. The complete audit (68 rated findings with file and
line references) lives in `AUDIT.md` in the repository.

**Remediation status:** several of these are already fixed for the
upcoming 1.1.0 (on the `fix/audit-remediation` branch) — those bullets
are marked *(fixed in 1.1.0)*. Everything unmarked is still open.

## WebXR engine

- **Centre-only hit testing.** `hitTest({x, y})` ignores its coordinates;
  placement is always at the centre reticle. Tap-point placement needs a
  ray-based hit test or an honest contract change. *(fixed in 1.1.0 —
  non-centre points run a ray-based hit test)*
- **Removed models aren't disposed.** Geometries, cloned materials and
  applied textures stay on the GPU after removal; plane-dot groups are
  removed without disposal too. Long product-browsing sessions grow GPU
  memory. *(fixed in 1.1.0 — disposal helper, ownership rule, capped
  model cache, `engine.dispose()`)*
- **Plane dots are one mesh each.** At the default spacing, a room-sized
  floor is ~460 extra draw calls, rebuilt on every plane change. An
  `InstancedMesh` redesign fixes both the cost and the dot disposal.
  *(fixed in 1.1.0)*
- **Reticle setting resets.** `showReticle: false` is forced back to
  `true` on session start, placement and removal. *(fixed in 1.1.0)*
- **Session-start failure can leak a live session** if reference-space or
  hit-test-source setup rejects after the session was created, and a
  fallback `hitTest` promise can hang if the session ends first.
  *(fixed in 1.1.0)*
- **`local-floor` or nothing.** Session creation hard-requires
  `local-floor` instead of falling back to `local`/`viewer`.
  *(fixed in 1.1.0)*

## Facade, hook and API shape

- **Hook transform shapes.** The hook's `placeModel` JSDoc says
  `{x, y, z}` objects; the engine wants arrays. Objects produce `NaN`
  transforms and invisible models. *(fixed in 1.1.0 — both shapes are
  normalised at the engine boundary)*
- **Hook plane counts always read zero** (event shape mismatch — the
  engine emits numbers, the hook reads array lengths). *(fixed in 1.1.0)*
- **`switchModel` material carry-over flattens multi-material models** —
  the first material is copied onto every material of the new model.
  *(fixed in 1.1.0 — materials matched by name, then traversal order)*
- **One active model, no enumeration.** The facade can't list placed
  models or clear them all; models placed by repeated `placeModel` calls
  become unreachable. *(fixed in 1.1.0 — `getPlacedModels()` /
  `clearModels()` on the engine, `ARView`, the facade and the hook;
  `ARView` tracks every placement)*
- **Shared hook engine.** All `useARCore` consumers share one engine;
  one unmount stops everyone's session. *(fixed in 1.1.0 —
  `useARCore({ engine })` drives an instance-scoped engine; the shared
  default remains for existing consumers and is constructed lazily)*
- **Four error conventions** across layers (thrown errors, `{hit:false}`,
  `{success:false, reason}`, coded screenshot errors). *(fixed in
  1.1.0 — one coded-error convention: `ARError` rejections and `code`
  fields on result-object failures)*
- **Importing the package requires React** (the entry re-exports the
  hook) and runs an event-bridge setup as an import side effect.
  *(partly fixed in 1.1.0 — the hook's supported entry is the
  `reticlexr/react` subpath and the event bridge installs lazily and
  idempotently; the root entry still re-exports the hook as a
  deprecated alias, so the root import still pulls React until the
  next major version)*
- **Two model-identifier systems** (`modelId` in the facade,
  `anchorId` in the engine) and two `placeModel` option shapes.
  *(fixed in 1.1.0 — `modelId` is canonical everywhere; `anchorId`
  and `modelPath` are deprecated aliases)*

## Native Android

- **Models never render natively.** `placeModel` keeps a metadata
  registry; GLB loading via gltfio is future work in the code's own
  words. This is the single biggest gap in the package.
- **Lifecycle hooks are not wired.** Pause/resume/destroy are never
  forwarded to the session or renderer; the render loop may not restart
  after a stop, and the Filament engine is never destroyed.
- **`checkSupport` always says yes** — it never asks ARCore for real
  availability.
- **Anchors are fictional.** Placements share the hardcoded id
  `"anchor_center"`; the `hitId` parameter is ignored; no real `Anchor`
  is ever created. `moveModel` consequently reports success without
  moving anything.
- **`Session.update()` is called from two threads** (render loop and
  bridge thread hit tests), which can desynchronise frames.
- **Availability retry is unbounded**, and `requestInstall` receives an
  application context cast to `Activity`, which fails on the install
  path.

## Packaging and docs

- **No `capacitor` metadata key**, so `cap sync` auto-discovery is
  unverified; the example includes the plugin in `settings.gradle` by
  hand.
- **No type declarations** ship, despite a React/Capacitor audience.
  *(fixed in 1.1.0 — hand-written declarations ship and are type-checked
  in CI)*
- **ESM sources in an undeclared-format package** (no `type: module`, no
  `exports` map, one extensionless dynamic import). *(the extensionless
  import is fixed in 1.1.0; `type: module` and the `exports` map are
  still outstanding)*
- **`three` and `@capacitor/core` are hard dependencies**, not peers —
  duplicate-copy risk for apps that also use three.
- **No lockfile, no tests.** CI syntax-checks the sources and builds the
  example; there is no test suite, no lint, no Android compile job.
  *(lockfiles fixed in 1.1.0; stub harnesses exist under
  `tests/harness/`, a real test suite is still outstanding)*

## Roadmap

### Quick wins

Hook plane counts (one line) · remove the forced reticle resets ·
native `checkSupport` delegates to the real availability check · pass
the Activity to `requestInstall` · wire pause/resume/destroy and reset
the render-loop flag · fix the extensionless import · add the
`capacitor` package key · dispose plane dots on removal · commit
lockfiles and switch CI to `npm ci` · a distinct insecure-context
reason from `checkSupport`.

### Medium efforts

Normalise the hook/engine transform contract, then hand-write type
declarations and type-check the JSDoc in CI · decide and implement the
hit-test contract · one disposal helper for remove/switch/stop paths, a
model-cache eviction API, and an `engine.dispose()` · plane dots via
`InstancedMesh` · serve native hit tests from the render loop's frame
snapshot · bounded availability retry and lazy Filament init · first
unit tests (gestures, hook event mapping) plus a Gradle assemble job in
CI · ~~a `reticlexr/react` subpath export with a lazy event bridge~~
*(done in 1.1.0)*.

### Larger decisions

**Native model rendering**: implement gltfio loading and real anchors
natively, *or* formally scope the native plugin to session + hit-test
and keep the claims corrected. Then: ~~unify model identifiers, option
shapes and one coded-error convention across runtimes; a per-instance
hook engine (or provider)~~ *(done in 1.1.0)*; code-split the AR stack
in the example; and
a TypeScript migration so this API reference can be generated instead
of hand-maintained.
